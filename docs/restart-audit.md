# 任务重启与怪物行为排查

用户报告：单人「雪花沉睡」中，历战王冰咒龙往地面吐冰后，玩家没有被冰黏住，冰咒龙仍使用了冻结后尾刺。正常情况下，这个追击只针对被冻住的目标。用户只在使用本工具重启任务时观察到这个现象。

目前仍未复现并确认触发条件，也没有确认工具导致了异常。以下记录已排除的范围和尚待对照的写入。

## 2026-10-24 补充（v0.3.7）

### 稳定与快速流程共同的写入

报告的异常已经在稳定流程中出现，因此仅属于快速重启的玩家动作、衣装写入不是充分解释。两种流程共同的写入如下：

| 写入 | 对象 | 状态 |
| --- | --- | --- |
| 受理与出发请求 | 受理、出发界面对象和出发标志 | 触发游戏自身的载入流程 |
| 出发附加字段 | `0x5011F58→+291C`，任务对象 `+17374`、`+17378` | 含义未确认，状态指纹对照中 |
| 综合套装 | 当前猎人存档中的装备、道具、转盘，以及猫饭对象 | 载入期间重复写入直到猎人就绪 |
| 道具栏刷新 | 游戏界面更新队列 | 只排入刷新请求 |
| 返回请求（稳定） | 返回窗口与回调对象 | 触发游戏自身的返回流程 |
| 力尽处理 | 任务对象 `+58 = 6`、`+38 = 7` | 力尽时直接结束任务 |
| 淡入淡出 | 映像中的两个常量 | 操作结束后恢复，见上表 |

当前代码仍然没有写入怪物对象链。特殊阶段判断只读取怪物对象。

### 状态指纹

v0.3.7 在日志中记录以下只读快照：

- `状态指纹（快速重启写入前）`：快速流程修改玩家状态之前。
- `状态指纹（工具出发前）`：受理完成，写入出发请求之前。
- `状态指纹（任务开始·工具出发）`：工具出发后，猎人进入可操作状态时。
- `状态指纹（任务开始·未经工具出发）`：工具空闲时，检测到任务从载入进入可操作状态。力尽回营地若经过载入，或工具操作在载入中途失败，也可能产生这一行，需要结合前后日志判断。

字段包括任务编号、任务阶段、`M291C`、`Q17374`、`Q17378`、`Q68`、玩家 `P62B0/P62C4/P62C8`、动作对象 `B4/E4` 和衣装 `5EC`。这些都是重启流程会写入、但游戏含义尚未确认的位置。如果“工具出发”与“未经工具出发”的任务开始时某项数值稳定不同，那一项写入就在载入后残留，成为优先怀疑对象；如果相同，说明游戏在载入时已经重新初始化该项。

### 建议对照

在同一次游戏启动内，使用同一套装备与插件环境：

1. A：不经工具，按游戏自身流程受理并出发。
2. B：工具稳定重启，选择“不使用综合套装”，关闭淡入淡出加速。
3. C：工具稳定重启，使用综合套装，保持其他设置不变。

每组进行相近次数，记录吐冰时是否被黏住、是否出现尾刺，以及当时的日志时间。工具通常承担大多数狩猎，少见的招式也会因此更多出现在工具流程中；只有次数相近的对照才能比较出现率。A 与 B 有差异时，嫌疑在返回、受理、出发的写入；B 与 C 有差异时，嫌疑在综合套装及其载入期间的重复写入。

第三方插件或任务修改在对照期间应保持一致，必要时另行隔离。本项目不自动移动或停用用户的插件。

## 2026-10-11 初次审查（v0.3.6）

基于 v0.3.5 源码的静态审查，当时的报告来自快速重启。

| 操作 | 源码中的写入对象 | 审查结论 |
| --- | --- | --- |
| 快速重启 | 玩家动作/衣装对象、任务控制对象与场景管理对象 | 跳过返回据点，存在需要实机对照的间接影响路径 |
| 稳定重启 | 游戏返回请求、任务结算状态与出发 UI | 先返回，再等待据点就绪并重新受理、出发 |
| 配装、道具与猫饭 | 当前猎人的存档内存、食事对象和游戏道具栏刷新队列 | 未发现通过怪物对象链写入 AI |
| 淡入淡出 | 可执行映像中的两个常量，操作结束恢复 | 仅在参数与支持版本的原值完全一致时缩短 |
| 特殊怪物阶段判断 | 怪物对象链 | 只读；读取失败时改用稳定重启 |

v0.3.6 加入的阶段读取失败改用稳定流程、淡入淡出原值核对以及重启上下文日志在 v0.3.7 保留。只有在同一环境中比较流程，或读到具体错误的状态，才能进一步判断因果。单次异常、成功出发日志和编译通过都不足以证明原因。
